# LedgerX Enterprise ERP & Digital Khata

Standalone enterprise retail, wholesale, and digital khata management platform tailored for Bangladeshi merchants with native bKash fintech aesthetics.

## Key Modules
- **Dashboard**: Real-time sales, collections, due summaries, cashflow trends.
- **Customer Khata (ক্রেতা খাতা)**: Customer balance ledger, transaction records, automated WhatsApp due reminders.
- **Supplier Khata (মহাজন খাতা)**: Supplier payable ledger, purchase records, split payments.
- **Express POS (কাউন্টার ক্যাশিয়ার)**: Fast barcode counter, dual unit pricing, discount manager, receipt generator.
- **Cashbox (ক্যাশবাক্স)**: Cash drawer balance, daily closing, denomination breakdown.
- **Inventory (মজুত স্টক)**: Stock tracking, morning repricer, batch expiry manager.
- **Halkhata (হালখাতা)**: Traditional Bengali fiscal year-end collection ledger.
- **Cheque Register (চেক খাতা)**: Dishonored, pending, and cleared bank cheque tracker.
- **Godown & Logistics (গুদাম চালান)**: Warehouse intake, inter-store transfers, chalani generator (Mushak 6.3 compliant).
- **Reports (হিসাব বিবরণী)**: True profit calculation, due ageing analytics, GST/Mushak tax reports.
- **System History & Doctor**: Audit trails, self-healing database integrity scans.

## How to Run
```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev
```

Or double click `Launch-LedgerX.bat`.
