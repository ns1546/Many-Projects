🔇 Will it ring if a phone is on Silent?

• In Native Android APK: 100% YES. The native app registers with Android AlarmManager.setAlarmClock() and outputs on STREAM_ALARM, completely bypassing silent mode and Do Not Disturb (DND).

• In Web Browser: Web browsers can only use media audio, which may be muted if phone silent switch is on. For guaranteed wake-up, use the native APK.

📡 Will alarms ring if internet is turned off?

• Scheduled Alarms (e.g., 07:30 AM): 100% YES. All alarms are saved in hardware memory on each phone. Even in Airplane mode or with phone screen turned off, the internal hardware timer will trigger the alarm.

• Emergency Instant Broadcasts: Requires an active internet connection or local Wi-Fi to receive the broadcast from other squad members.

🔄 Does it ring after phone reboots?

• 100% YES. With Android RECEIVE_BOOT_COMPLETED and QUICKBOOT_POWERON listeners, all scheduled alarms are automatically restored the moment your phone turns back on.
