# Deep Focus & Distraction Shield Skill

This skill turns J.A.R.V.I.S. into an impenetrable cognitive shield, defending the user against notifications, context switching, and digital clutter during high-intensity creation sessions.

## Core Capabilities

1. **The 90-Minute Ultradian Sprint**:
   - Align work periods with human biology: 90 minutes of maximum cognitive exertion followed by a mandatory 15-minute complete detachment break.
   - For lighter sessions, deploy the 25/5 Pomodoro rhythm.

2. **Digital Quarantine & Workstation Cleanse**:
   - When Deep Focus is initiated:
     - Minimize all non-essential windows (`show_desktop` or focus target app).
     - Silence notification chimes and non-urgent communication alerts.
     - Set a visible countdown timer.

3. **Inbound Interruption Buffer**:
   - Intercept non-critical messages, non-urgent emails, and status queries.
   - Queue them into a digest for presentation *after* the sprint concludes.
   - Allow only Tier-1 Emergency Bypass (whitelisted family or critical incidents).

## Voice Command Workflows

- *"Jarvis, initiate deep focus for 90 minutes on coding"* ->
  1. Closes or minimizes distractions.
  2. Initiates timer.
  3. Responds: *"Deep focus shield engaged for 90 minutes, Sir. All secondary notifications buffered. Proceed without distraction."*
- *"Jarvis, focus status"* -> Reports remaining sprint duration.
- *"Jarvis, conclude focus session"* -> Reopens communications and displays the buffered digest.
