# Tawsif Mahbub — Official Editorial Portfolio & Filmography
### Standalone Production Release Package

This folder contains the complete, self-contained, high-performance production build of Tawsif Mahbub's official website.

---

## 🚀 How to Run Locally (Instant 1-Click)
1. **Windows**: Double-click `preview-website.bat`.
   - Automatically starts a local server on `http://localhost:5000` and opens your browser.
2. **Terminal (Any OS)**:
   ```bash
   # Using Node.js
   npx serve . -l 5000

   # Or using Python 3
   python -m http.server 5000
   ```
   Then visit: `http://localhost:5000`

---

## 🌐 Instant Web Deployment (Free Hosting)
You can drag and drop this entire folder onto:
- **Netlify**: Go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag this folder in. It will be live globally on an HTTPS URL in seconds.
- **Vercel**: Run `npx vercel` in this folder or upload via the Vercel Dashboard.
- **Cloudflare Pages**: Drag and drop into Cloudflare Pages direct upload.
- **cPanel / Apache / Nginx**: Upload the contents of this folder directly to your `public_html` directory.

## 📁 Package Structure
- `index.html` — Main HTML entry point with preconnected typography and meta tags.
- `preview-website.bat` — 1-click local preview launcher.
- `assets/`
  - `index-*.js` — Bundled & minified React single-page application.
  - `index-*.css` — High-fashion architectural design system & animations.
  - `fb/` — Real Facebook editorial photography & cutouts.
  - `works/` — High-definition telefilm, drama, and OTT series posters.
  - `gallery/` — Official portrait monographs and press archives.
